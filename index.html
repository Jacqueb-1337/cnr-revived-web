CNR REVIVED SERVER

Replacement Multiplayer Backend

CNR Revived Web is the Node.js multiplayer backend built for the Cops N Robbers Revival project. It replaces the discontinued services expected by the original Android client while preserving the game's existing multiplayer flow.

How It Works

Room discovery

The revived client retrieves room information from the replacement backend instead of depending on the original service.

Hosting and joining

The server handles the master-to-game-server flow required to create rooms, redirect clients, and join sessions.

Live matches

The restored stack has been validated end to end with the original game client. The revival uses the networking behavior the Unity client already understands rather than replacing the gameplay layer.

Client, Mods, and Tools

The server is one part of the larger CNR Revival project. Client-side work includes server redirection, a reusable C# mod loader, the in-game mod manager, HUD and settings tools, recording support, and compatibility fixes.

Project V7

The original Cops N Robbers build is a 32-bit ARMv7 Android application. Project V7 provides the compatibility layer used by the revival on supported 64-bit-only Android devices.

Project V7 is a separate open-source Android compatibility project for running supported legacy 32-bit apps and games on modern hardware.
