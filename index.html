What is CNR Revived Web?

CNR Revived Web is the replacement multiplayer backend built for the community Cops N Robbers Revival project. The original Android client expected online services that are no longer available, so the revival project reverse engineered the client-server behavior and recreated the pieces needed for multiplayer.

The server is written in Node.js and implements the master-server and game-server flows required by the revived client. Its purpose is preservation: keep the original game's multiplayer behavior usable without replacing the game itself with a remake.

Restored multiplayer features

Room discovery

The revived client can retrieve a room list from the custom backend instead of relying on the discontinued original service.

Hosting and joining

The server handles the flow required to create rooms, redirect clients and join multiplayer sessions.

Live matches

End-to-end gameplay has been validated through the replacement multiplayer stack.

Photon-era protocol behavior

The server reproduces the networking behavior expected by the original Unity client, including the TCP-based path used by the revival.

How it connects to the main CNR Revival project

The server is one part of a larger preservation stack. The Cops N Robbers Revival project contains the revived client work, mod loader, gameplay-side modifications, release builds and reverse-engineering documentation.

The revived client uses a mod layer to redirect multiplayer traffic to the replacement server. Other modules provide features such as an in-game settings and HUD editor and optional recording support.

Project V7 attribution and modern Android support

The original Cops N Robbers game is a legacy 32-bit ARMv7 Android application. Current 64-bit-only Android devices may not be able to launch it natively.

Project V7 provides the compatibility work used to run supported legacy 32-bit Android software, including Cops N Robbers, on modern 64-bit-only devices. Project V7 is developed as a separate open-source Android compatibility project and is an important part of the current preservation path.

Technical overview

The server uses Node.js and exposes separate master and game services. In the current revival architecture, the master side handles discovery and room-related coordination while the game side carries in-room traffic.

The wider CNR Revival work includes reverse engineering of the original Unity and Photon-era client behavior, custom C# injection and runtime mod loading. That allows the server and client compatibility layers to evolve independently.
